# 🔬 Research & Publication

## ✈️ Aero-Engine Remaining Useful Life Prediction

My research focuses on predicting the **Remaining Useful Life (RUL)** of aircraft engines using deep learning.

### GEBiLSTM-Attn Architecture

A hybrid architecture integrating:

* CNN
* GRU
* BiLSTM
* Gated Feature Enhancement
* Attention Mechanisms

### NASA CMAPSS Results

| Dataset | R² Score   |
| ------- | ---------- |
| FD001   | **0.8726** |
| FD002   | **0.8346** |
| FD003   | **0.8893** |
| FD004   | **0.8355** |

The project includes an end-to-end pipeline covering preprocessing, sequence generation, training, hyperparameter optimization and evaluation.
